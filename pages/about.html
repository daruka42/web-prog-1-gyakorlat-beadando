Információk

Ez az oldal információkat tartalmaz a weboldal készítőjéről és a projekt céljáról.

Rólunk

Ez a weboldal a Web-programozás 1 tantárgy házi feladataként készült, amely bemutatja a HTML, CSS és JavaScript alapvető használatát.

A készítő

A weboldalt Sik Dominik készítette, neptun kód: Q60PVQ . A projekt célja, hogy bemutassa a modern webes technológiák használatát.

A projekt célja

A weboldal több aloldalból áll, amelyek különféle HTML elemeket, CSS stílusokat és JavaScript funkciókat mutatnak be, beleértve a táblázatkezelést, űrlapvalidációt és HTML5 újdonságokat.

Technológiák

  • HTML5
  • CSS3
  • JavaScript
  • Reszponzív design
  • Űrlap validáció
